# AI Face Attendance System

**AI Face Attendance System** is a **Flutter-based mobile application** that leverages **artificial intelligence and facial recognition** to automate attendance tracking. It provides **real-time, accurate, and contactless** attendance recording for schools, offices, workshops, and other environments.

---

## Features

- **Real-time Facial Recognition** – Detect and recognize faces instantly  
- **Automated Attendance Marking** – Records attendance with timestamps  
- **Cross-Platform** – Built with Flutter for **iOS and Android**  
- **AI-Powered Accuracy** – Uses machine learning models for recognition  
- **Secure & Private** – Data can be stored locally or on a backend server  
- **User-Friendly Interface** – Clean and intuitive UI built with Flutter widgets  

---

## Technologies Used

- **Flutter & Dart** – Cross-platform mobile development  
- **TensorFlow Lite / OpenCV** – Facial recognition and detection  
- **Firebase / SQLite** – Backend and attendance storage  
- **Machine Learning Models** – AI for face detection and recognition
